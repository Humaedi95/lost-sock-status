One status update, in the voice of a lost sock that woke up in the freezer
next to a bag of peas — and has something to say about it.

Entry (under 120 characters):

> Status update: I'm in the freezer with the peas. Freezing, stiff, and they keep bragging about their matching pair.

## How it works

`main.ts` holds the entry as a plain string constant and writes it to
`/output/entry.txt` (creating `/output` if needed). It is fully
self-contained: no network, no external files. Run it with Node 22:

```sh
node main.ts
```
